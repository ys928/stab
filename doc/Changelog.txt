# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

When cutting a release, add a new section for the version (matching the git tag
without the leading "v", e.g. tag v0.3.1 → heading "## 0.3.1"), then push the
tag from the main branch. GitHub Actions will publish that section as the
release notes.

## 0.3.1 - 2026-08-15

### Added
- Redesigned web connections dashboard with a branded live sessions view,
  connection count, empty state, and clearer disconnect actions.
- Multi-platform release builds for Linux, macOS, and Windows (amd64 / arm64).
- Automatic GitHub Release publishing from version tags on main, with notes
  sourced from this changelog.

### Changed
- Simplified config initialization (`default_config` / `hash_secret` helpers)
  and fixed Axum disconnect route path params to `{port}`.
- Debug builds reload `index.html` from disk for faster UI iteration.
- Moved the English readme to `doc/readme_en.md`.
- Updated dependencies (tokio, axum, clap, serde, serde_json, and others).

## 0.3.0 - 2024-11-09

### Added
- TCP tunnel CLI with server and local client modes.
- Web dashboard for viewing connections and disconnecting sessions.
- Heartbeat detection, traffic stats, and multi-port links.
